# Parallel Physically Based Ray Tracer

A physically-based CPU ray tracer written in modern C++ and inspired by:

- [_Ray Tracing in One Weekend_](https://raytracing.github.io/books/RayTracingInOneWeekend.html)
- [_Ray Tracing: The Next Week_](https://raytracing.github.io/books/RayTracingTheNextWeek.html)

The project focuses on:
- physically-based rendering concepts
- Monte Carlo ray tracing
- multithreaded rendering with OpenMP
- renderer architecture and performance experimentation
